# Summary
This folder contains scripts to test associations between variables of interest and circulating omega-3 fatty acid levels.

asso_pgs_pheno.touchscreen.r: perform association, correlation tests, and plotting using information from the baseline touchscreen questionnaire. This script is used in discovery, replication and sensitivity analyses. 

asso_pgs_pheno.diet24h.r: perform association, correlation tests, and plotting using information only from the 24-hour dietary recall questionnaire. This script is only used in sensitivity analyses. 

job_submit.sh: script to submit all jobs
